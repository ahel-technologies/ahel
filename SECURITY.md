# Security

Report a security issue with the Ahel plugin or the Ahel service to support@ahel.ai with "Security" in the subject. Please do not open a public issue for it. We reply within two working days.

This repository holds only plugin configuration: the plugin connects your agent to Ahel's hosted MCP server at `https://mcp.ahel.ai` over HTTPS with OAuth. No keys or secrets are stored here.
